# MNIST Model Training

MNIST 데이터셋을 이용하여 CNN 기반 숫자 인식 모델을 학습하고
학습된 모델을 TensorFlow Lite 형식으로 변환하는 과정입니다.

## Environment

### Software

* Python
* Jupyter Notebook
* TensorFlow
* NumPy

## Practice

### 01. MNIST Dataset

MNIST 데이터셋을 불러와 학습 데이터와 테스트 데이터를 전처리합니다.

* MNIST Dataset
* Data Preprocessing
* Image Normalization
* Training Data
* Test Data

### 02. CNN Model

MNIST 데이터를 이용하여 CNN 모델을 학습합니다.

* Convolution
* Max Pooling
* ReLU
* Fully Connected Layer
* Softmax
* Model Training
* Model Evaluation

### 03. TensorFlow Lite

학습된 모델을 TensorFlow Lite 형식으로 변환하여
Raspberry Pi에서 사용할 수 있도록 모델을 저장합니다.

* TensorFlow Model
* TFLite Conversion
* Model Export

## Files

* MNIST_Training.ipynb
* mnist_model.tflite
